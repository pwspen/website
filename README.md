
# GitHub Pages

In the repository's **Settings → Pages**, set **Build and deployment → Source**
to **GitHub Actions**. The Pages workflow builds the Astro site and publishes
`dist/`; it can also be started manually from the Actions tab. This is separate
from the existing server deployment workflow.
